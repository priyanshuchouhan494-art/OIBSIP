#Iris Flower Classification

##OASIS INFOBYTE Internship - Data Science Task 1

This project focuses on classifying iris flowers into three species:
-Setosa
-Versicolor
-Virginica

##Technologies Used

-Python
-Pandas
-Scikit-learn
-Matplotlib
-Seaborn
-Jupyter Notebook

##Project

The project uses machine learning classification models to identify the species of an iris flower based on its physical measurements
